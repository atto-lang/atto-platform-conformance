## Fixed-width arithmetic extension (candidate host contract, 2026-11-26)

`tests/fixed-width-integer-oracle.test.mjs` checks signed and unsigned 8/16/32/64-bit mathematical ranges against separate add/sub/mul range preflight logic. All eight Node tests passed locally on Node 22.16.0, with every possible pair of 8-bit operands for each of three operations (393216 assertions across i8/u8), and deterministic edge-pair and 10000 generated operand-pair checks per larger type. Exact test Git blob: `02ea6ed1724687d49cf49396cdc9dab4d88d684b`. Host arithmetic only; not an Atto guest test, not a new normative syntax declaration, and not evidence for a backend.

Canonical integration proposal (subject to existing language specification): preserve width and signedness at literal admission, typed HIR/MIR, constant folding, parameter/return types, and target lowering. For checked add/sub/mul, each intermediate result must be within its declared mathematical range before subsequent evaluation. Do not silently wrap, narrow, or reinterpret signedness; do not optimize away an observable arithmetic fault. A full-width observer is required. Numeric fault representation and division, shifts, conversions, wrapping and saturation require separate specification alignment and tests. Existing u64 corpus remains unchanged.
