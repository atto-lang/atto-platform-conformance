# Portable Task / HasFuture v1 — proposals, NOT guest-certified

All 16 files are shared AttoLang **candidate** programs; the test hook vocabulary is not yet an implemented public ABI. This repository's `npm test` runs manifest integrity / receipt rejection tests only and MUST NEVER be cited as guest execution. `node bin/portable-task-v1.mjs` shows the fail-closed backend matrix; without actual receipts it exits 1 and reports `not_executed` for all 176 backend/case cells.

Two-phase rollout: (1) approve `contracts/portable-task-v1.md`, settle ActorRef await identity, and implement a narrow, capability-gated guest probe ABI; (2) run each byte-identical fixture using Java's current guest launcher and LLVM's `scripts/compile-aot.sh` on SHA-pinned source checkouts, then add Rust-authored compiler, distinct Cranelift, Wasm host, Forge, .NET, JS, self-hosted bootstrap, HDL and realtime profiles. The compiler must fail closed for anything unsupported. Positive programs must really execute and emit trace events; negative programs must fail at the actual compiler and never execute. Do not rewrite fixtures differently per backend or substitute a Node/C++/Java host model for guest execution.

A receipt must name the compiler/fixture commits and raw source blob/digest, actual compiler steps, actual guest artifact, guest exit and output, and a positive-step Actions run link. `lib/portable-task-v1.mjs` gives only preliminary structural classification: even a candidate `passed` is not release qualified until independently verified against immutable workflow logs and Git objects. Source-local Actions runner allocation remains an external blocker; no cross-org export is authorized by this PR.

**Gate behavior:** the structural matrix command exits nonzero even if all submitted receipts look like candidate passes, because `releaseQualified` is deliberately false. The direct execution runner returns exit 3 for 16 structural candidate passes awaiting independent log/artifact review, 1 for incomplete/failed/unsupported coverage and 2 for invalid invocation. Neither stdout JSON nor a locally forged Actions URL can self-authorize promotion.

The 11 role keys match `atto-source.*`. `rs` is not Cranelift; `wasm` is a separate guest integration/admission lane, not a second independent source compiler. `atto` is a bootstrap target. HDL and realtime are constrained profiles; executed explicit rejection remains `unsupported`, not a passing general-purpose runtime claim. All 16 source blobs are now independently pinned in the manifest. Deterministic replay builds on these existing fixtures; no scheduler probe ABI or backend guest execution is established by this expansion.
