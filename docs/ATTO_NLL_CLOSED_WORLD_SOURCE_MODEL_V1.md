# Closed-world loan-token source model (NON-PROMOTING)

`src/ownership-nll-closed-world-v1.mjs` provides a **candidate-only** bounded straight-line token stream for shared/exclusive borrows, loan uses, source moves, and suspension. It derives last use indexes directly from the supplied operation stream. It rejects unminted/reused loan tokens, mismatched place and mode, unknown use tokens, mixed manual releases, missing final uses, unclassified reads/calls/sends/awaits, early moves and suspension while a loan's annotated uses remain outstanding. Additional conservative checks reject borrowing a previously moved owner, double moves, overlapping exclusive and shared/exclusive loan spans on the same place, and empty streams with no use proof. Independent owners and non-overlapping borrow lifetimes remain candidate-only.

Raw JSON input can omit real source uses or forge token identities. Therefore EVERY model result has `ok=false`, `verified=false`. Deriving an offset from untrusted input is not SSA, compiler provenance, or guest authorization.
