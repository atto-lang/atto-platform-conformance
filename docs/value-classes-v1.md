# Proposed value-class conformance (NOT EXECUTED)

[Value-class v1 registry](../contracts/value-classes-v1.json) contains 5 positive and 14 negative `.atto` fixtures. Every backend is explicitly marked `NOT_EXECUTED`: the host-only registry checker cannot claim compiled guest execution or implementation parity. Track normative requirements in [atto-spec #60](https://github.com/atto-lang/atto-spec/pull/60) and the Rust browser safety gate in [atto-source.rs #252](https://github.com/atto-lang/atto-source.rs/pull/252).
