# Mixed-width ECS physical golden fixture v1

Status: **source-free physical ABI reference**, not language/source guest compilation or parity certification. This draft is stacked on shared ABI PR #145 and corresponds to tracker #144's layout/ABI and verification tasks.

`contracts/v1/mixed-ecs-physical-v1.json` is fixed golden data (not dynamically generated by the backend being tested) for `id:u32`, `x:f64`, `flag:bool`, `next:ref32`, under all four physical data layouts. It includes immutable expected per-segment bytes and physical base offsets, total allocation bytes, and row/field address probes. `ref32` is only an encoded word: a matching four-byte stored value is **not** an authorized actor pointer.

| Layout | Live rows | Bytes in segments | Bytes physically allocated | Notes |
| --- | ---: | --- | ---: | --- |
| AoS | 3 | 72 | 72 | 24-byte aligned record stride |
| SoA | 3 | 12, 24, 3, 12 | 56 | 51 payload bytes + 5 base-alignment bytes |
| AoSoA | 5 | 144 | 144 | tile width 4, two 72-byte tiles (three padded tail lanes) |
| SoAoS | 3 | 24, 48 | 72 | separate grouped subrecords `[id,flag]`, `[x,next]` |

The fixture includes raw IEEE-754 binary64 values (signed negative zero, 1.25 and 42.5), maximum unsigned `u32`, and both null and non-null encoded `ref32` words. It does not conflate logical payload bytes with physically reserved aligned bytes.

`test/mixed-ecs-physical-v1.test.mjs` verifies every layout against the existing checked reference planner: exact segment widths/bases, exact probe addresses, natural alignment, exhaustive byte-level nonalias, bounds, and allocation/padding. It separately writes the logical rows into a real `ArrayBuffer` / `DataView` using little-endian primitive writes, then checks the raw binary64 bits, integers, booleans, reference words, and zeroed unoccupied padding. Five negative golden-data mutations must all fail, preventing circular self-certification.

The exact committed fixture and test blobs were executed in an isolated V8 test runner with the unchanged exact GitHub ABI module; **2/2 focused tests passed** including all negative cases. This is **not** an independently executed GitHub Actions job, not `node --test`, and not source compiler or native guest execution. Users can run `node --test test/mixed-ecs-physical-v1.test.mjs` once a permitted runner has the branch checked out.

**Next acceptance steps:** import this immutable fixture into real JS and Wasm runtime tests, add equivalent independent .NET/LLVM/GraalVM runtime checks, then require actual compiled Oreslang source execution and exact tree evidence from all five. Native host layout matches do not imply source-lowered actor owned heaps, generational ECS row handles, or benchmark speedups.
