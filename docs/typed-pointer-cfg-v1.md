# Typed pointer CFG v1 — host reference model (draft)

Companion to atto-spec #287. An explicitly bounded closed CFG verifier consumes typed allocation, slot, loan and construction events. Type identity, byte size/alignment, actor domain, storage phase, generation and derived loans remain distinct. Joins require equal abstract state, including retirement; this conservative v1 does not infer path-dependent ownership or dynamic loop generations. Mutable access requires a compiler-provided exclusive proof plus no conflicting modeled loans or slots. The boolean proof field is a placeholder from trusted typed compiler IR, not a public authority or proof producer. Only Copy scalar reads are modeled as copies. Non-Copy reads are loans.

Construction is begin, ordered field initialization, commit or reverse rollback followed by abort. Destroy is modeled as an atomic lifetime event; no real destructor is executed. Free retires the allocation identity. Suspend rejects live slots, loans or incomplete construction. Unknown/escaping operations reject. Closed paths must release all authorities. Model does not execute source, allocate guest storage, prove actual field layout, generate native addresses or certify concurrency. Generation exhaustion is guarded, but reaching the maximum in this bounded model is not tested. A production implementation must derive all authority facts from trusted type/ownership IR rather than source claims and prove destructor execution, nonescaping self, cancellation, actual storage alignment and dynamic generations.
