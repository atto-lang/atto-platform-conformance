# Oreslang eight-feature hardening gate — 2026-10-18

Status: **AUDIT / NOT A RELEASE CERTIFICATION**. This is an acceptance matrix, not evidence that draft branches have landed or executed. Existing source features must fail closed where executable lowering or ownership proofs are missing.

| Async iterators and async generators | Pulling a channel is destructive, not broadcast; iterator close must not close its non-owned channel. No unsanctioned guest turn or borrowed value may cross suspension. | Java #394, #728, #740, #909. | Records vs positional tuples | A tuple is exact-width and ordered; a record is field-named. `(T,U)` can abbreviate the *type* `tuple (T,U)`; `(x)` is grouping, while the current executable *value* constructor is explicit `tuple(x)` / `tuple(x,y)`. No implicit record-to-tuple conversion, positional argument explosion, mutable width cast or erased reinterpretation. Static tuple spreading evaluates each source expression once, in order, and checks expanded arity before invoking the callee. | Java #1211, #1299, #1335, #1397; backend structural tuple admission is staged. Only uncaught ordinary `throw` becomes the error side. | Java #1316 (current-main draft), #1129 (older draft); no unchecked result forgery or silently discarded error slots. |

## Release gates (all mandatory)

1. **Parser:** canonical and compatibility spellings have explicit acceptance/rejection fixtures, including each forbidden implicit conversion and invalid constraint.
2. **Static admission:** ownership/lifetime/effect/type analysis must reject unsafe programs *for the intended reason*, not because a fixture accidentally failed parsing or name resolution.
3. **Host/runtime:** deterministic guest tests verify execution ordering, single evaluation, cleanup, task quiescence, strict option/result variants, no leaks and no double notification.
4. **Backend parity:** execute source fixtures through Java JDK25/GraalVM/JIT/AOT, LLVM, and every advertised backend. Unsupported backends must issue explicit semantic diagnostics before running user effects.
5. **Formal/differential evidence:** model-check finite cancellation/unwind/refinement state machines with unsafe mutants and link state transitions to actual compiler/runtime entrypoints. Differential TypeSpec/JSON Schema instances must include an intentional schema-drift mutant that fails.
6. **Provenance:** record exact Git commit and tree SHA, immutable dependencies, executable workflow job steps, test counts and negative results. Zero-step Actions failures are `NOT_EXECUTED`, not compiler regressions and not passes.
7. **Security:** private compiler source may be mirrored only to a destination allowed under the source repository's independent export authorization policy. A funded organization's available GitHub Actions minutes do not themselves authorize transferring a private Git tree. See Java issue #962 and the approved-repositories gate.

## Immediate sequencing
